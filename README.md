Customer Churn Analysis
Project Overview
This project demonstrates an Excel-based customer churn analysis using a 30-record customer dataset.
The analysis focuses on identifying customer churn patterns, calculating key churn metrics, analysing churn by contract type, region, and support tickets, and presenting the findings through tables and charts.
Objectives

Calculate total customers and churned customers
Calculate the customer churn rate
Analyse average monthly customer spend
Analyse average customer tenure
Compare churn across contract types
Analyse churn by region
Investigate the relationship between support tickets and churn
Create clear data visualisations
Demonstrate practical Excel data analysis skills

Key Results

Total Customers: 30
Churned Customers: 12
Churn Rate: 40%
Average Monthly Spend: R716.33
Average Tenure: 20.1 months
